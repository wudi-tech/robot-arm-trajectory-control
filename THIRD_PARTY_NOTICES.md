# Third-party notices

This project uses external runtimes and libraries; their implementations are not vendored in this archive:

- MATLAB, a proprietary MathWorks product, provides the numerical environment and graphics/video functions.
- PyBullet/Bullet provides simulation, URDF loading, inverse dynamics and the `pybullet_data` plane asset at runtime. Those assets remain in the installed distribution.
- NumPy and pandas provide Python numerical arrays and CSV handling.
- OpenCV provides MP4 encoding and video inspection.

Install dependencies from their respective distributions and retain their applicable notices. This archive does not grant rights to third-party software or institutional/course materials. No repository-wide source reuse license has been selected; existing source headers have been preserved.

The trajectory formulas, geometric kinematics and PID/computed-torque control are standard robotics techniques. The course report references robotics textbooks and official software documentation. Their text and illustrations are not republished here. A course assignment image and full report/decks have been omitted.
