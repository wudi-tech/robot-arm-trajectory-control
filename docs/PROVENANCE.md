# Provenance and publication selection

This archive combines two existing course-project folders as a progression: planar 2-DOF comparison and spatial 3-DOF planning/control simulation. It is a publication selection, not the original submission package.

The revised course report is the preferred source when older notes disagree, especially for the quintic accuracy conclusion and the MATLAB/PyBullet dynamics boundary. For personal contribution, the repository owner's explicit confirmation takes precedence over generic division-of-work text in the course report: independent development of kinematics, trajectory planning and control simulation. The course submission also involved reporting, slides and presentation by group members; this repository does not claim their writing or presentation as the owner's independent work. Team names, student identifiers and the original division-of-work page are not reproduced.

The project applies established geometric inverse kinematics, polynomial time laws, trapezoidal velocity profiles, PID and inverse dynamics. Source inspection did not identify a bundled upstream repository license or copyright header. That is not proof that every line or method is individually original. Existing source text and any notices are retained; no new blanket license is assigned.

`SOURCE_MANIFEST.csv` maps each selected copy to a relative source-project label and source filename, with SHA-256 and size. Source programs, URDFs, CSVs and selected images were copied byte-for-byte. New files are the archive navigation, technical documentation, dependencies, `.gitignore`, notices and validation records. The original source directories are not edited.

Excluded from public selection:

- Original reports, slides, PDFs and assignment screenshots containing identities, student lists or irrelevant institutional/personal details.
- Earlier report/PPT revisions and the duplicate `3dof robotic arm.zip` submission snapshot.
- `sim2.m`, which is byte-identical to the retained `main_baseline.m`.
- Local editor settings, caches, environments and internal assistant workflow plans/specifications.
- Repeated MP4 animations, editable `.fig` duplicates of the selected PNGs, thumbnails, review render folders and duplicate media.
- Original chats, private local paths, private audit inventories and account credentials.

No project date or independent-author claim is inferred from file timestamps. The archive preparation date records only this publication work.
